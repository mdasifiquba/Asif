# Storefly - Full Stack Web Application

Storefly IT & Security Services management platform.

## Architecture
- **Frontend**: Next.js 16 (`storefly-web`)
- **Backend**: Express & TypeScript REST API (`storefly-api`)
- **Database**: MySQL (`netcet_database.sql`)

## Deployment
- **Frontend**: Deploy `storefly-web` on [Vercel](https://vercel.com)
- **Backend**: Deploy `storefly-api` on [Render](https://render.com)
- **Database**: Host MySQL on [Aiven](https://aiven.io) or [TiDB Cloud](https://tidbcloud.com)
